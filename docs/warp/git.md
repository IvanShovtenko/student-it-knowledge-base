# Zestaw komend WARP do udokumentowania

| Polecenie | Znaczenie |
|`git clone`|Pobranie repozytorium i utworzenie lokalnego katalogu|
|`git status`|Sprawdzenie gałęzi oraz plików zmienionych i przygotowanych|
|`git add`|Dodanie konkretnego pliku do obszaru staging|
|`git commit`|Zapis przygotowanych zmian z czytelnym komunikatem|
|`git push`|Publikacja nowej gałęzi i ustawienie śledzenia|
|`git fetch`|Pobranie informacji o zmianach bez modyfikowania plików roboczych|
|`git branch`|Wyświetlenie lokalnych gałęzi i oznaczenie aktywnej|
|`git switch`|Utworzenie gałęzi roboczej i przełączenie na nią|
|`git log`|Skrócony podgląd pięciu ostatnich commitów|
